## Closeout rules

- One item per outcome. Reuse an existing item instead of adding a duplicate.
- An item leaves `## Open` when it is resolved or tracked elsewhere; move it to
  `## Resolved` with evidence. Do not delete it silently.
- Every open item needs the smallest next action and an owner. Use
  `waiting-owner` when a product or owner decision is required.
- No secrets, credentials, personal data, financial amounts, or raw logs.
- Keep this file small. Link the issue, PR, or document that holds the detail.
